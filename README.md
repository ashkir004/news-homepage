# News Homepage

A small responsive news homepage built with SvelteKit. This repository contains the source for a Frontend Mentor "News homepage" challenge implementation.

Live site: https://news-homepage-ashkir004.netlify.app/

## Quick start

- Install dependencies: `npm install`
- Run dev server: `npm run dev`
- Build for production: `npm run build`
- Preview production build: `npm run preview`
